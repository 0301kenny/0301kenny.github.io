How I Work

AI 加速每一步，判斷與品質由我負責

不是同時會三種職位，而是能把同一個產品從定義、設計、實作到驗證完整推進。

01

Discover

Research

使用者訪談、問卷與數據觀察，找出真正要解決的問題。

02

Define

PM

釐清商業目標與規則，寫成 PRD、User Story 與例外情境。

03

Design

UI / UX

資訊架構、流程與介面設計，建立元件與設計 Token。

04

Build

Frontend

HTML/CSS 與 Vue 實作，用 Claude Code 把設計直接做進專案。

05

Validate

QA

UI QA、跨平台與多語系驗收，追蹤問題直到上線。
