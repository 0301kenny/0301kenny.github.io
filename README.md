# Kenny Cheng · Product Designer Portfolio

鄭偉助的作品集網站，以 Astro 建置，部署於 GitHub Pages。

- 網站：https://0301kenny.github.io
- 內容：`src/data/profile.ts`、`src/data/cases.ts`（中英雙語）
- 開發：`npm run dev`
- 產生履歷 PDF：開著開發伺服器（port 4322）時執行 `npm run pdf`

本網站以 Claude Code 協作開發。案例圖片包含公開頁面截圖、UI Spec 開發環境截圖（畫面資料皆為假資料），以及依專案數據重繪的示意圖。
